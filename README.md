# Palette Diary

A minimal photo palette extractor. Upload a photo and get its dominant colours as hex codes, ready to copy.

**Live demo:** https://chengwq95.github.io/palette-diary/

## Features

- Extracts up to 6 dominant colours from any photo
- Runs entirely in the browser; photos are never uploaded anywhere
- Single HTML file, no build step, no dependencies

## Run locally

Open `index.html` in a browser.

## Files

| File | Purpose |
|---|---|
| `index.html` | The standalone app |
| `palette-diary.jsx` | React component version of the same extractor |
